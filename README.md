# 史努比屏保

在安卓手机上看史努比屏保。画面会自己换：房间、史努比的动作、路过的角色，以及一段时间后切进来的全屏视频。视频和屏保之间用原版那种擦除遮罩过渡。

这个仓库里是播放器的源码。画面素材大约 7.2GB，不在仓库里，下载地址写在下面。

有两个可以同时装在手机上的应用：

| | 正式版 | 天气版 |
| --- | --- | --- |
| 桌面名称 | 史努比屏保 | 史努比屏保·天气 |
| 包名 | `com.snoopysaver.android` | `com.snoopysaver.weather` |
| 版本 | 1.0 | 1.1-weather |
| 工程目录 | `SnoopyScreensaver` | `SnoopyScreensaver-weather` |

正式版只负责播放。天气版在同样的播放之上，可以按当前城市的天气优先换画面。两个应用各自保存自己的进度，装天气版不会覆盖正式版。

手机上可以当普通应用打开，也可以在系统的屏保列表里选用。屏幕保持常亮，按返回键退出。天气版底部有一行提示：长按可以设置天气。

## 能做什么

播放：

- 全屏房间。有的是静止画面，有的是循环的背景视频。
- 史努比的站立、换姿势、小动作，以及偶尔走过来的访客。
- 隔一段时间切进一段全屏视频，再用遮罩擦除回到屏保。
- 第一次打开时，如果手机里还没有素材，会提示选择 `SnoopyAssets` 文件夹，并打开「允许访问所有文件」。

天气版另外可以：

- 长按屏幕，等手指抬起后再出现设置。这样松手不会误点到面板上的控件。
- 填写城市，例如「上海」。城市用 [Open-Meteo](https://open-meteo.com/) 查询，不需要申请密钥。
- 开关「按天气更换画面」。勾选框在文字后面。勾上之后，雨、雪、阴天、雾、雷暴、大风这些画面会优先出现。
- 天气结果缓存 1 小时。查不到天气时继续播普通内容。
- 城市和这个开关单独保存。关掉开关只是暂停按天气选画面，城市还在。下次打开应用，只要没手动关掉，会继续按这座城市换画面。
- 长按后的状态会写成「已开启：城市名」。

## 做过的改进

### 天气版单独放一个工程

天气功能写在 `SnoopyScreensaver-weather`，正式版留在 `SnoopyScreensaver`。两边的包名不同，可以一起留在手机上。

### 设置会被记住，也不容易被误点

播放进度和天气设置分开存放，所以保存播放记忆时不会把城市或开关清掉。

设置面板改成深色底、白色字。开关文案是「按天气更换画面」，不再使用「关闭天气」这类按钮文字，避免广告拦截一类的工具把设置页自动点掉。

### 建筑能画出来

一部分建筑、墙壁的文件名是 `.heic`，文件内容其实是 PNG、JPEG 或 WebP。以前一律按 HEIF 去解码，这些图会被丢掉。现在先看文件头再决定怎么解，透明的建筑层可以叠到房间上。

### 视频和屏保切换时不再回闪

屏保切到视频时，当前画面先留着，视频在下面准备好。遮罩真正打开的那一帧，再让视频和擦除一起出现。这样不会先露出视频，又被屏保盖回去一下。

视频回到屏保时，擦除开头有几帧是整片绿色，表示洞完全打开、视频应该继续露着。这几帧以前被当成灰度蒙版。绿色的亮度大约是 182，于是屏保会先浅浅盖住视频，下一帧又撤掉。现在一整片纯色保留原来的透明度，全开的帧保持全开，视频会一直露着，直到擦除真的开始合上。

隐藏的视频层改成可以透明，并丢掉过期的「第一帧已经画好」通知，避免切场景时闪出上一张画面。

夸克网盘：<https://pan.quark.cn/s/76e94aad2ae1?pwd=myYJ>

提取码：`myYJ`

解压后得到文件夹 `SnoopyAssets`。放到手机内部存储的根目录，路径类似：

`内部存储/SnoopyAssets`

应用也会在「下载」「电影」「文档」下面寻找同名文件夹。允许「访问所有文件」之后，重新打开应用就会进入屏保。

电脑上编译不需要把这 7GB 放进工程目录。素材只在手机上读取。本机如果已经有 `F:\Snoopy\SnoopyAssets`，那个文件夹和旁边的 `SnoopyAssets.zip` 都被 Git 忽略了，不会上传。

## 在电脑上编译

需要安装：

- [Android Studio](https://developer.android.com/studio)
- Android SDK，编译用的 API 是 36，最低能装的系统是 Android 9（API 28）

两个目录各自是一个完整工程。用 Android Studio 打开 `SnoopyScreensaver` 或 `SnoopyScreensaver-weather`，等它同步完，再点 Run 装到手机上。

工程里带了 Gradle Wrapper，版本是 9.1.0。Android Studio 会自己使用它。

命令行编译调试包时，在对应工程目录里执行：

```bat
gradlew.bat :app:assembleDebug
```

生成的安装包在 `app\build\outputs\apk\debug\app-debug.apk`。正式版和天气版要分别编译、分别安装。

`local.properties` 里只有你自己电脑的 SDK 路径，没有放进仓库。Android Studio 打开工程时会按本机位置重新写一份。

## 这个仓库里有什么

```text
SnoopyScreensaver/            正式版
SnoopyScreensaver-weather/    天气版
README.md                     本说明
```

每个工程里，播放逻辑主要在这些文件：

- `Director.kt`：什么时候换房间、播视频、做擦除
- `SnoopySession.kt`：画面层、视频播放、第一次打开时的素材引导
- `StageView.kt`：房间、角色和遮罩怎么画
- `Heic.kt`：按文件内容解码 HEIC、PNG、JPEG、WebP，以及遮罩
- `Engine.kt`：素材目录和播放规则
- `Weather.kt`：只有天气版有，负责城市和 Open-Meteo

`app/src/main/assets/asset-index.json` 是素材清单，用来知道每个画面有哪些文件。它不是画面本身。

史努比的形象和原版屏保素材属于各自的权利人。这里发布的是自己写的安卓播放器。
