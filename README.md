# 史努比屏保

这是一套安卓上的史努比屏保。房间自己换，史努比会站着、换姿势，偶尔有人从旁边走过。过一会儿，一段全屏视频切进来，再用素材里原来的擦除遮罩回到屏保。

屏幕保持常亮。返回键退出。它可以当普通应用打开，也可以在系统的屏保列表里选用。

源码在这个仓库里。安装包在 [v1.0](https://github.com/Lee1639/SnoopyScreensaver/releases/tag/v1.0)。`SnoopyScreensaver.apk` 是正式版，桌面显示史努比屏保，包名 `com.snoopysaver.android`，版本 1.0。`SnoopyScreensaver-weather.apk` 是天气版，桌面显示史努比屏保·天气，包名 `com.snoopysaver.weather`，版本 1.1-weather。两个可以一起装，播放进度各记各的。包是调试签名，手机要允许未知来源。

## 素材放在手机里

画面大约 7.2GB，安装包里没有，Git 仓库里也没有。夸克网盘是 https://pan.quark.cn/s/76e94aad2ae1?pwd=myYJ ，提取码 `myYJ`。

解压出来的文件夹叫 `SnoopyAssets`，放到内部存储的根目录。应用还会到下载、电影、文档下面找这个名字。第一次如果读不到，会让你自己选文件夹，并打开允许访问所有文件。允许完再进一次。

在电脑上编译时不用把这 7GB 拷进工程。手机才读它。仓库根目录如果放着 `SnoopyAssets` 或 `SnoopyAssets.zip`，Git 不会带上它们。

## 天气版

正式版只负责播。天气版在同样的播放上面，按当前城市的天气挑画面。城市交给 [Open-Meteo](https://open-meteo.com/) 查，不用申请密钥，查到的结果留 1 小时。接口没有返回时，就接着播普通内容。

设置要长按。手指抬起来以后面板才出来，免得松手正好点在控件上。底是深色的，字是白的。开关写着「按天气更换画面」，勾选框跟在这行字后面。勾上之后，雨、雪、阴天、雾、雷暴、大风这些画面会先被选到。再长按，能看到已经开启，后面跟着城市名。

城市和这个开关分开存，不跟播放记忆放在同一个地方。保存播到哪一张的时候，不会把城市清掉。取消勾选只是先不按天气换，城市还留着。下次打开，只要没有自己取消，还会按这座城市换。

面板上曾经有一颗写着「关闭天气」的按钮。手机里的 GKD 广告拦截看到关闭两个字就会去点，长按没多久设置自己关掉了。按钮拿掉以后，换成现在这个开关。

## 建筑和切换

有一批房子和墙，扩展名写着 `.heic`。打开文件头，看到的是 PNG、JPEG 或 WebP。当时播放器一律按 HEIF 去解，解不开就丢掉，房间里就缺了这些建筑。现在先读文件头，再决定用哪种解码。透明的一层可以叠回房间上。

屏保切进视频时，当前画面先停在上面，视频在底下准备。遮罩打开的那一帧，视频和擦除一起出现。旧的顺序是视频先全屏露出来，屏保又盖回去一帧，然后再被擦开。

从视频回到屏保，擦除的开头有几帧整片都是绿的。绿色表示洞完全打开，视频应当继续露着。这几帧颜色是平的，程序把它们当成灰度蒙版来读。绿色的亮度大约 182，满刻度是 255，屏保就先盖上一层，浓度大概三成，下一帧洞又被完全挖开。纯色的帧现在保留自己原来的透明度。全绿就保持全开。视频一直露着，擦除真正往回合的时候，屏保才出现。

底下那层视频默认不透明。透明度写成 0，它也挡着屏保，所以改成可以透明。上一张画面如果晚到，第一帧已经画好的通知会被丢掉。

## 自己编译

要用 Android Studio。编译 SDK 是 36，最低能装到 Android 9，也就是 API 28。`SnoopyScreensaver` 和 `SnoopyScreensaver-weather` 各是一个工程，用 Android Studio 打开其中一个，等同步完，点 Run。

工程里带了 Gradle Wrapper，版本 9.1.0。也可以在工程目录里执行

```bat
gradlew.bat :app:assembleDebug
```

安装包会出现在 `app\build\outputs\apk\debug\app-debug.apk`。两个版本要各编一次，各装一次。

`local.properties` 只有本机的 SDK 路径，没有提交。Android Studio 打开工程时会按这台电脑重新写一份。

## 代码放在哪

`SnoopyScreensaver` 是正式版，`SnoopyScreensaver-weather` 是天气版。播放节奏写在 `Director.kt`，画面层和第一次找素材写在 `SnoopySession.kt`。`StageView.kt` 把房间、角色和遮罩画出来。`Heic.kt` 认文件、做解码。素材目录和播放规则在 `Engine.kt`。天气版另有 `Weather.kt`。

`app/src/main/assets/asset-index.json` 是一份清单，记录每个画面有哪些文件。清单里没有图像。

史努比的形象和原版屏保素材属于各自的权利人。这里放的是自己写的安卓播放器。
